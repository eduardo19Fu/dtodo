Facturación electrónica (FEL)

Código de establecimiento asignado por la SAT para esta sucursal.

El código de establecimiento no puede estar vacío.
03

Inventario inicial

Copia el inventario de una sucursal existente hacia esta sucursal nueva. A partir de ese momento cada una se administra por separado.

El inventario se copia una sola vez al crear la sucursal; después cada sucursal se actualiza manualmente.
